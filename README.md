# LABEL ATLAS

品牌故事、服裝歷史與設計探索。

- 網站：https://10969ethan.github.io/label-atlas/
- 時光機（獨立預覽）：https://10969ethan.github.io/label-atlas/time-machine/

每次推送到 `main`，GitHub Actions 會自動部署到 GitHub Pages。

- `time-machine/data-source.js`：時光機資料原始檔（與 index.html 內嵌資料相同）
